# 🔌 API-тестирование

Тестирование REST API с использованием Postman.

## 📋 Проект включает:

- позитивное и негативное тестирование;
- проверку статус-кодов;
- проверку структуры JSON-ответов;
- проверку обязательных и необязательных параметров;
- тестирование CRUD-операций;
- автоматизированные проверки с помощью Postman Tests.

## 🛠️ Инструменты

- Postman
- REST API
- JavaScript
- JSON
