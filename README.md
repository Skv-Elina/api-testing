# 🔌 API-тестирование

Тестирование REST API [Интернет-магазина](https://intern.demoshopping.ru/) с использованием Postman.

## 📋 Проект включает:

- проверку статус-кодов;
- проверку структуры JSON-ответов;
- проверку обязательных и необязательных параметров;
- автоматизированные проверки с помощью Postman Tests.

## 🛠️ Инструменты

- Postman
- REST API
- JavaScript
- JSON
